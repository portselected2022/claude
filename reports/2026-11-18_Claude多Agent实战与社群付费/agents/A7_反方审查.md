## 3. 已核实无误的关键数字

- **Claude Code 专长研究**（2026-06-16）：约 40 万个交互会话，约 23.5 万人，2025-10 至 2026-04，不含 `claude -p`。严格口径成功率：新手 15%，中级及以上 28–33%（合并区间）；部分成功 77% 对 91–92%；遇到麻烦时放弃 19% 对 5–7%；每条提示约 5 个动作、600 词，专家约 12 个、3,200 词；修 bug 的会话占比 33%→19%，操作软件 14%→21%，写作与数据分析约 10%→20%。
- **多 agent 研究系统**（2025-06-13）：在内部研究评测上比单 agent 的 Opus 4 高 90.2%；token 约为聊天的 15 倍；BrowseComp 上 token 用量单独解释 80% 的方差；"大多数编码任务"可并行的部分少。
- **《Cadences》**（2026-06-26）：写博客或文章，聊天和 Cowork 中位来回 13 轮，Claude Code 只要 1 次人工提示；31 类产出里有 26 类在 Claude Code 上自主度更高；问卷约 9,700 份，不具代表性。
- **C 编译器**（2026-02-05）：16 个 agent，近 2,000 个会话，两周，花费略低于 2 万美元，约 10 万行 Rust，能构建可启动的 Linux 6.9；GCC 对照和三条局限与报告一致。
- **4.6 黑客松**（2026-04-20）：入选 500 人；5 位获奖者里 4 位不是职业开发者；冠军是人身伤害律师，"一行代码没写"；首次提交打回率 90% 以上，平均拖 6 个月。
- **4.7 黑客松**（2026-06-15）：MaestrIA 的知识文件含 17 条规则、19 个基准价格；在 12 个案例、9 个维度上从 74% 升到 81%；系统提示没改；标准答案由做木匠的父亲给出；本场只有它写了防注入和限流。
