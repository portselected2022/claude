- Cadences（2026-06-26，E1 WebFetch）：数据 2026-04-10~06-10 chat+Cowork；Claude Code 同期纳入自主度比较。93% 对话产出 artifact；解释 17%、文档报告 15%、指导 11%；代码/技术约 1/6。Claude Code 自主度在 31 类产出中 26 类高于 chat/Cowork，平均高 0.37 分（1–5 分）；脚本代码差 0.53；数据/表格例外（chat/Cowork 3.09 vs Claude Code 2.74）；约 2/3 差距来自同类任务在 Claude Code 上委托更多；博客文章 chat/Cowork 中位 13 轮 vs Claude Code 1 次提示；Sonnet 内差距 0.26。自主度与 token r=0.68。工作日个人用途约 35%，周末近 50%。博客/文章 81% 为工作、营销内容 80%、数据库查询 82%。调查约 9,700 人（非代表性）：86% 报速度提升、82% 范围、69% 质量、27% 成本；1/3+ 预期明年 AI 处理大部分任务；10% 认为自己可能失业。Claude Code 会话 54% 由 Opus 服务（chat/Cowork 10%）。未给出分平台任务类别占比与自动化占比时间序列。
- 多 agent 研究系统（Anthropic 2025-06-13，E1）：Opus 4 主 + Sonnet 4 子；内部研究评测比单 agent Opus 4 高 90.2%；agent ≈4× chat token，多 agent ≈15×；BrowseComp 上 token 用量解释 80% 方差，三因素 95%；并行工具调用最多缩短 90% 研究时间；适合广度优先、可并行、信息超单窗口、工具多；不适合需共享上下文/依赖多的任务，"大多数编码任务"属此类；早期一个简单查询派出 50 个子 agent；规则：简单事实 1 agent 3–10 次调用，对比 2–4 子 agent 各 10–15 次，复杂研究 10+ 子 agent；评测从约 20 条真实查询起步；LLM 评审 0–1 打分；错误会累积、需断点续跑、彩虹部署；同步执行是瓶颈。Research 功能用途：跨专业领域开发软件 10%、专业技术内容 8%、业务增长策略 8%、学术研究与教材 7%、人物/地点/机构信息核查 5%。
